# Cursor Landing Page Clone

A pixel-perfect frontend clone of the [Cursor.com](https://cursor.com) landing page. This project demonstrates proficiency in modern HTML5 and CSS3, focusing on layout accuracy, flexbox, and positioning.

## 🚀 Features

- **Responsive Navigation Bar**: Fixed positioning with split alignment for logo and menu items.
- **Hero Section**: Typography and spacing matched to the original design using the 'Inter' font family.
- **Modern UI Styling**: Implementation of the dark-themed aesthetic using precise color variables.
- **Icon Integration**: Used Remix Icons for UI elements.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Flexbox, Fixed Positioning, Google Fonts integration.
- **Assets**: Remix Icons, External Images.
